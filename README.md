# G2P TechOffice + Aura Music Studio
Elite local-first web platform for complex business operations: file/folder management, software deployments, AI model builds, music studio functions. Optimized for desktop/laptop performance with File System Access API.

## Features
- Local folder access & operations (create, structure, cleanup)
- Music studio booking & portfolio
- AI-assisted ops & simulations for latency/memory
- PWA-ready for desktop-like experience

## Run
Open index.html in Chrome/Edge (File System Access API). Or serve with any static server.
