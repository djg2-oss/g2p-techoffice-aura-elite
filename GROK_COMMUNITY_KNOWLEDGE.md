1. Sim A writes state/memory to shared local store (localStorage key `g2p-os-memory` or File System).

3. Sim C calls remote host only if local proves insufficient.
Nested deeper sims feed upward. Memory compounds. Latency drops because most work stays local-first on the owner's computer.
